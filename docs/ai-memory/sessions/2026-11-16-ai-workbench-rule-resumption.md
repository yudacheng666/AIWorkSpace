# 2026-11-16｜AIWorkSpace 日常工作台规则的恢复场景澄清

## 用户补充
用户指出：一个工作台事务即使已经开始，如果几天后继续跟进，ChatGPT 处理时也应继续遵守相关规则。单纯写“每个独立事务开始前读取”容易让 AI 误解为只在最初读取一次。

## 结论
- 将触发条件从“开始新的独立事务”扩大为“每次开始或恢复任何事务”。
- 明确跨日恢复即使仍在原对话，也必须重新读取 GitHub main 的最新规则。
- 新对话接续、上下文中断后恢复、切换 AI 接手也必须重新读取。
- 规则在整个事务生命周期持续生效，不是一次性开场检查。
- 同一连续工作时段内即时追问无需每条消息重复读取；若 main 规则可能更新，则下一次写入前重新读取。

## 实施
- 更新 `docs/AI_WORKSPACE_OPERATING_RULES.md` 第 1 节。
- 更新 `AGENTS.md` 日常工作台规则入口。
- 更新 `DECISIONS.md`、`PROJECT_STATE.md` 持久化该澄清。
- 不改产品代码、测试代码、VERSION 或真实工作台数据。
