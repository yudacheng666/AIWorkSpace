# AIWorkSpace UI V2 — 独立测试版

这是供你体验 UI V2 第一至第三阶段的**临时测试版本**，不是正式部署，也不连接真实工作数据。

## Windows 使用方法
1. 从 GitHub PR #12 对应成功的 Actions 下载 `AIWorkSpace-UI-V2-isolated-preview` Artifact ZIP，并解压到任意测试目录。
2. 双击根目录 `start_ui_v2_preview.bat`。
3. 弹出的命令窗口会启动独立本机端口并自动打开浏览器。Python 3 是唯一运行依赖；不要求 Node。
4. 可以创建**虚构**项目和任务，查看四种任务视图、项目关系和任务详情。
5. 操作结束回到命令窗口，按 Enter。程序停止并清理临时数据。

## 安全约束
- 服务仅绑定 `127.0.0.1`，选择一个独立可用的随机端口，不占用正式 `8770`。
- 程序文件在 Windows 临时目录中复制运行；数据只存在该临时目录的 `test-data-only` 文件夹。
- **不会读取或修改**公司电脑现有的 AIWorkSpace 程序目录、真实 Google Drive 文件夹、现有任务/项目/步骤台账。
- 关闭后临时演示数据删除，所以请勿录入需要保留的真实工作事项。
- 请不要在本测试版本点击“系统设置 → 立即更新”；此项属于独立验收范围，而不是 UI 体验。
- 若运行失败，请保存命令窗口错误文字反馈，不要修改公司的正式启动方式。

**版本来源**：GitHub `feat/20261031-ui-v2-phase3-projects`，以具体 Actions 运行 SHA 为准。PR #10/#11/#12 仍未合并，正式软件尚未升级。
